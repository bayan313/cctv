# 🛡️ Study Monitor & Parental Screen Archive

കുട്ടികൾ പഠന ആവശ്യങ്ങൾക്ക് കമ്പ്യൂട്ടർ ഉപയോഗിക്കുമ്പോൾ അവരുടെ സ്ക്രീൻ നിരീക്ഷിക്കാനും, സുരക്ഷിതമായ വെബ്സൈറ്റിലൂടെയും ടെലിഗ്രാമിലൂടെയും രക്ഷിതാക്കൾക്ക് അത് കാണാനും ഉള്ള പൂർണ്ണ സൊല്യൂഷൻ.

---

## 🚀 പ്രധാന സവിശേഷതകൾ (Key Features)

1. **Auto-Start & 10s Delay:**  
   കമ്പ്യൂട്ടർ ഓൺ ചെയ്യുമ്പോൾ സോഫ്റ്റ്‌വെയർ തനിയെ റൺ ആകും. 10 സെക്കൻഡിനു ശേഷം ആക്റ്റീവ് ആകും.

2. **Overt Screen Popup:**  
   റെക്കോർഡിംഗ് ആരംഭിക്കുമ്പോൾ സ്ക്രീനിൽ മുകൾ ഭാഗത്തായി വ്യക്തമായ മുന്നറിയിപ്പ് പോപ്പ്-അപ്പ് വരും:  
   `⚠️ SCREEN RECORDING ACTIVE: Your computer is under screen recording for study monitoring.`

3. **10 FPS Screen Recording:**  
   കുറഞ്ഞ സൈസിലും ഉയർന്ന വ്യക്തതയിലും 10 FPS-ൽ വീഡിയോ ക്ലിപ്പുകളായി റെക്കോർഡ് ചെയ്യപ്പെടുന്നു.

4. **Telegram Bot Alerts (@my_library_data_bot):**  
   കമ്പ്യൂട്ടർ ഓൺ ആകുമ്പോൾ നിങ്ങളുടെ ഫോണിലെ ടെലിഗ്രാമിലേക്ക് ഉടൻ അലർട്ട് വരും. പുതിയ റെക്കോർഡിംഗുകൾ ടെലിഗ്രാമിൽ ലഭ്യമാകും.

5. **Secure Web Dashboard:**  
   ശക്തമായ മാസ്റ്റർ പാസ്‌വേഡ് ഉപയോഗിച്ച് മാത്രം തുറക്കാവുന്ന വെബ് പോർട്ടൽ. മൊബൈലിലോ കമ്പ്യൂട്ടറിലോ ബ്രൗസറിൽ നിന്ന് തുറക്കാം. 1.25x, 1.5x, 2x സ്പീഡിൽ വീഡിയോ പ്ലേ ചെയ്യാം.

6. **24-Hour Auto-Delete:**  
   24 മണിക്കൂറിലധികം പഴക്കമുള്ള പഴയ റെക്കോർഡിംഗുകൾ സെർവർ തനിയെ ഡിലീറ്റ് ചെയ്യും (സ്റ്റോറേജ് നിറയില്ല).

## 📁 ഫയലുകൾ (File Structure)

* `config.json` - പാസ്‌വേഡ്, ടെലിഗ്രാം ടോക്കൺ, എഫ്.പി.എസ് തുടങ്ങിയ കോൺഫിഗറേഷൻ.
* `start_server.bat` - വെബ് പോർട്ടൽ ആരംഭിക്കാൻ (ഡബിൾ ക്ലിക്ക് ചെയ്യുക).
* `install_startup.bat` - കമ്പ്യൂട്ടർ ഓൺ ആകുമ്പോൾ തനിയെ റൺ ആവാൻ വിൻഡോസ് സ്റ്റാർട്ടപ്പിലേക്ക് ചേർക്കാൻ.
* `uninstall_startup.bat` - എപ്പോഴെങ്കിലും സ്റ്റാർട്ടപ്പിൽ നിന്ന് നീക്കം ചെയ്യാൻ.
* `client/recorder.py` - സ്ക്രീൻ റെക്കോർഡർ ആപ്പ്.
* `server/server.py` - വെബ് പോർട്ടലും ഓട്ടോ-ക്ലീനറും ടെലിഗ്രാം ബോട്ടും.

## 🛠️ എങ്ങനെ ഉപയോഗിക്കാം (How to Use)

### ഘട്ടം 1: Telegram Bot കണക്റ്റ് ചെയ്യുക
1. നിങ്ങളുടെ ഫോണിൽ Telegram തുറക്കുക.
2. [t.me/my_library_data_bot](https://t.me/my_library_data_bot) സെർച്ച് ചെയ്ത് തുറക്കുക.
3. താഴെയുള്ള **Start** ബട്ടൺ അമർത്തുക (അല്ലെങ്കിൽ `/start` എന്ന് അയക്കുക).
4. ബോട്ട് നിങ്ങളുടെ അക്കൗണ്ട് അഡ്മിൻ ആയി ലിങ്ക് ചെയ്യും!

### ഘട്ടം 2: വെബ് സെർവർ സ്റ്റാർട്ട് ചെയ്യുക
* `start_server.bat` ഡബിൾ ക്ലിക്ക് ചെയ്യുക.
* ബ്രൗസറിൽ `http://localhost:8899` എന്ന് ടൈപ്പ് ചെയ്യുക.
* **Default Password:** `Study@Safe2026`  
  *(പാസ്‌വേഡ് മാറ്റാൻ `config.json` ഫയലിലെ `admin_password` മാറ്റാം).*

### ഘട്ടം 3: കമ്പ്യൂട്ടറിൽ ഓട്ടോ-സ്റ്റാർട്ട് സെറ്റ് ചെയ്യുക
* `install_startup.bat` ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക.
* ഇനി കമ്പ്യൂട്ടർ റീസ്റ്റാർട്ട് ചെയ്താലും 10 സെക്കൻഡ് കഴിഞ്ഞ് റെക്കോർഡിംഗ് തനിയെ ആരംഭിക്കും!
